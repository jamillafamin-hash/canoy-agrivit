# CANOY AGRIVIT - Agricultural Supplies E-Commerce Website

## Project Overview
CANOY AGRIVIT is a responsive e-commerce website for agricultural supplies and gardening products, built for IT105 Web Development course.

**Tagline:** Grow Naturally, Harvest Beautifully

## Features
- Responsive design with mobile navigation
- Product catalog with search and filters
- Shopping cart with localStorage persistence
- Simulated checkout with validation
- Contact form with validation
- Product images from local assets

## Technology Stack
- HTML5, CSS3, Vanilla JavaScript
- Local Storage for cart
- GitHub Pages compatible

## How to Run Locally
1. Open the project folder
2. Start a local server: python -m http.server 8000
3. Navigate to http://localhost:8000

## Pages
- index.html - Home page
- shop.html - Product catalog
- cart.html - Shopping cart
- checkout.html - Checkout (demo)
- contact.html - Contact form
- about.html - About page

## Notes
This is a frontend demonstration. No real payments or backend processing.
